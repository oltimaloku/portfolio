## Project Overview

CampusQuery is a web application designed to make UBC campus data more accessible and interactive. The project transforms static campus information into a dynamic, user-friendly experience that allows students, faculty, and visitors to explore campus data in meaningful ways.

## Key Features

### RESTful API

Built with Express and TypeScript, the backend provides a robust API for accessing campus information:

- Room and building data
- Course scheduling information
- Campus facilities and services
- Geographic location data

### Interactive Map Interface

The React-based frontend offers an engaging map view that allows users to:

- Explore campus buildings and locations
- View building details with a click
- Filter and search for specific facilities
- Get directions and location information

### Tabular Data Views

For users who prefer structured data exploration:

- Sortable and filterable tables
- Export capabilities
- Advanced search functionality
- Detailed record views

## Technical Implementation

### Backend Architecture

- **TypeScript**: Type-safe development for reliability
- **Express**: Fast and minimalist web framework
- **RESTful Design**: Well-structured API endpoints
- **Data Processing**: Efficient handling of campus datasets

### Frontend Development

- **React**: Component-based UI architecture
- **Interactive Maps**: Leaflet integration for geographic visualization
- **Responsive Design**: Works across devices and screen sizes
- **State Management**: Efficient data handling for smooth user experience
